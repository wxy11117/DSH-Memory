# 小屋素材与许可

本包 room/ 来自项目既有海边小屋第八版，并增加本地插件连接。人物、暖色海边风格、家具、阁楼、厨房、钢琴、海景与星空保持既有实现。

- dayu.png 为用户提供的角色图；dayu-actions.png、dayu-walk.png 沿用依据该人物参考生成的动作图集。人物素材的权利不因本插件代码使用 MIT 自动转移或变成公共领域。
- anime-coast.png 与 coast-panorama-v4.png 为既有生成海景素材，本次没有新增生成或修改图片。
- 房间家具、厨房、暖气、船只、鱼缸等使用本地 Three.js 几何体；界面图标和电脑屏幕由代码绘制。
- 钢琴乐谱及海浪通过本地 Web Audio 合成，没有引入第三方录音；音频只在用户操作后开启。
- Three.js 0.180.0，MIT 许可原文位于 room/vendor/LICENSE。
- Astronomy Engine 2.1.19，MIT 许可原文位于 room/vendor/ASTRONOMY-LICENSE.txt。
- HYG v4.1 明亮恒星子集由 David Nash / Astronexus 及 HYG contributors 提供，遵循 CC BY-SA 4.0。完整署名、变更说明、来源及许可保存在 room/data/README.md、room/data/HYG-LICENSE.txt 和 room/data/stars-hyg-v41.json。该数据沿用自己的许可。

本地小屋不从外部网站加载运行所需的图片、字体、模块或模型接口。
