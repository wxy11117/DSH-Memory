# 0.2.0-preview.3 试安装说明

本包包含记忆插件和本地活动面板。下载、解压本身不会修改 DSH；运行安装脚本才会切换插件登记。当前为预览测试版，公开发布状态以仓库 Releases 为准。

请使用 preview.3 的安装器。preview.2 及更早版本含有在部分 Electron 运行时下可能误删插件目录的清理路径，不应再运行它们的安装器或加载测试。

## 先看界面

不安装也可以用浏览器打开 `dashboard/index.html`。默认显示明确标注的合成示例；导入自己的脑文件可查看一次快照。

## 安装到自己的 DSH

1. 保留当前可用插件的完整目录，并备份正在使用的记忆文件。使用桥接扩展的用户应备份其实际指定的脑文件。
2. 将 ZIP 完整解压到长期保留的文件夹，解压后应只有一个 `dsh-hippocampus` 根目录。
3. 正常退出 DSH，再双击 `tools/install.cmd`。需要 Node.js 22+，包装器会寻找可用运行时；不要求 Git 或 npm。
4. 确认安装器报告成功，再启动 DSH。安装器只验证登记和包结构，真正启动情况以 DSH 本次运行结果为准。
5. 对 DSH 说“给我记忆面板地址”。若未调用工具，明确说“请调用 hp_dashboard，把完整链接给我”。点击返回链接查看。

面板服务随插件在后台启动，不主动弹出浏览器。同一次运行共用地址，重启或重新加载插件后重新获取。网页打开且可见时每 60 秒更新；动画在本地运行，不调用大模型。

安装使用目录链接。装好后不要移动、删除或重命名解压目录。安装器会备份 profile 的 package.json，不会自动备份脑文件，也不会覆盖用户的桥接配置。

新安装器替换链接时仅移除链接自身，保留它所指向的旧源码；如遇真实的旧安装目录，会将其重命名为同级 `.hp-backup-…` 备份。切换链接或写登记失败会尝试回退，并报告未完成的步骤。

## 如果需要恢复旧插件

正常退出 DSH，保留本版目录。在 **preview.3 解压目录** 中打开终端，使用本版安装器指定旧目录：

```powershell
.\tools\install.cmd -Plugin "D:\Plugins\旧版插件目录"
```

将示例路径替换为先前保留的、包含 `package.json` 的可用插件目录。确认登记通过后再启动 DSH；如需指定 profile，可追加 `-Profile "实际 profile 目录"`。这样只切换目标，避免再次运行旧安装器的清理代码。不要手动删除记忆文件或整个 profile。

如 DSH 无法进入正常界面，可先在其恢复界面停用该插件；旧版故障说明见 `STARTUP-RECOVERY.md`。本预览使用独立的面板启动流程，但不能保证所有宿主版本、第三方插件组合与本地配置都无故障。

## 能看到什么

- 当前活跃记忆、归档、四层分布、活动时间线、七天统计和三维词语关系网。
- 插件本地模式按操作记录活动；桥接扩展采用文件观察，只能记录发现的文件变化，不能还原每次纯检索或接入前的历史。
- 正文默认隐藏。面板只读，不会因点击、旋转或查看而强化、删除或改写记忆。
- 新记忆仍由 AI 调用记忆工具提交，插件执行筛选、存储和维护规则；不是自动保存每句聊天。

包内不含个人记忆、QQ 账号配置、访问凭据或本机试运行日志。每位使用者连接自己的记忆库。
