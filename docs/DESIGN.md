# 设计说明：为什么长这样

> 这份文档解释 `lib/hippocampus.js` 的每一个机制**为什么存在**。
> 想直接看公式与参数，跳到第 6 节；想看它做不到什么，跳到第 9 节。

---

## 1. 四条关于人的假设

记忆系统不是数据库，它的每个设计都该能追到一个关于「人怎么记事」的假设：

| 假设 | 落成的机制 |
|---|---|
| 记忆不是开关，是渐变 | 指数衰减 `R = exp(-Δt/S)` + 连续稳定性 S，不用「到期删除」 |
| 越重要的事越不容易忘 | 稳定性 `S = 类别基线 × (0.45 + 重要度×1.25) × (1 + 情绪×0.65)` |
| 越想起越牢，冷落就掉 | 每次成功回忆 `S ×= 1.6`（间隔效应）；同类竞争 `S ×= 0.88`（提取诱发遗忘） |
| 人记的是意思，不是原文 | 同类 ≥3 条小事 → 熬成一条「道理」（语义归纳），原件归档 |
| 记忆按关系网扩散 | 词与词反复共现就长边，从一个词能扩散 1–3 圈（水波纹） |

**四层（瞬时/短期/长期/永久）不是输入，是输出。** 先算 S，再由 S 落在哪个区间反推层名。
反过来做（先定层再决定留多久）就会变成四个抽屉，而不是记忆。

## 3. 写入：先过闸门，再算寿命

### 3.1 闸门 `shouldEncode()`

不是所有事都配进记忆。规则：

- `promise` / `self`（约定、自我认知）→ 一定写；
- `watch` / `daily`（刷到的东西、流水账）→ 重要度必须 ≥12；
- 其余（吃饭、去过哪、和人相处）→ 放行，但寿命由分数决定。

### 3.2 打分 `scoreMemory()`

```
基底 30（长期类 70）
+ 第一次/头一回           +26（情绪 0.6）
+ 最/特别/难忘            +22（情绪 0.5）
+ 答应/约定/承诺          +20（情绪 0.3）
+ 难过/哭/委屈/后悔/生气  +16（情绪 0.7）← 坏记忆反而更牢
+ 一辈子/永远/从此        +12（情绪 0.4）
+ 文本 ≥40 字             +6
− 刷到/刷视频            −14
− 吃了饭                 −10
− 没什么/还行            −12
− 文本 ≤8 字             −8
→ 夹在 0–100
```

### 3.3 寿命 `baseStability()`

```
S(小时) = 类别基线 × (0.45 + 重要度/100 × 1.25) × (1 + 情绪 × 0.65)
food/place 最低 14h；结果夹在 0.5–60000h
```

类别基线：`watch 2 · daily 3 · food 10 · place 12 · misc 20 · event 40 · feeling 50 · study 80 · person 240 · promise 8000 · self 20000`。

### 3.4 去重

前 20 字相同视为同一条：`hits+1`、重要度取 max、`S ×1.3`、关系网重学。
**重复说同一件事是巩固，不是新增。**

## 4. 遗忘：曲线 + 清算，没有掷骰子

```
R = exp(-Δt / S)          Δt 从「最后一次被触碰」算
R < 0.06 → 清算
```

清算 `sweep()`（每分钟）：

1. `pinned` → 跳过（钉住的不进曲线）；
2. `R ≥ 0.06` → 留着；
3. 否则 `sealed || S ≥ 72h` → 进 `archive`（写 `archivedAt`）；
4. 否则 `forgotten++`（真的没了）。

**关键区别**：长期/封存只归档、不真丢；只有短期且未封存的流水才会消失。
归档上限 600 条，超了砍最旧的。

## 5. 想起：三条不同的路

| 场景 | 函数 | 规则 |
|---|---|---|
| 固定回忆（每天 21:05） | `pickRecall` | 只从长期/永久挑；`R ∈ [0.06, 0.9]`；3 天内想过跳过；权重 `(1−R) × (0.5 + 重要度/100)`，永久再 ×0.6 —— **越模糊越容易被想起** |
| 被话头勾起 | `probe` | 2-gram 重合 ≥1 才考虑；`p = 0.10 + 重合比×0.55 + R×0.35`；中 → 加固 + 从归档捞回；未中 → `missCount+1`、`S ×0.92` |
| 漫无目的联想 | `ripple` | 从一个词扩散 1–3 圈，圈权重 `[1, 0.55, 0.3, 0.16]` |

三种都会调 `reinforce()`：`S ×1.6`、`hits+1`，并把**同类兄弟** `S ×0.88`
（想起 A 会压 B——这是「提取诱发遗忘」，不是 bug）。

## 6. 每轮装配：8 块，按固定顺序

```
① 【说好的事】     到期提醒（remindAt）
② 【不能忘的】     钉住的（最多 8 条）
③ 【我认识的人】    category=person，按 重要度×R（最多 5 条）
④ 那年今日         同月同日（≥1 年 / 整 365 天 / 整 30 天，最多 3 条）
⑤ 【这会儿想起来的】 按当前来信检索（没有话头就按层发牌）
⑥ 【记下的道理】    语义归纳（≤3 条）
⑦ 【顺着话头想起来的】水波纹联想（带免责句：不保证对得上）
⑧ 【今天想起来的】  今天的固定回忆结果
```

每条的行格式：

```
- [类] 文本（X 前记下，提过 N 次，订正过 N 次，是从几件小事里归纳出来的，记不太清了）
```

清晰度由 R 决定：`≥0.7` 正常、`0.4–0.7`「，记不太清了」、`<0.4`「，只剩个模糊的影子」。

---

## 7. 语义归纳：把三件小事熬成一条道理

```
同类 ≥3 条 + 有共同 2-gram（出现在 ≥2 条里）
→ 生成「「火锅」这类事发生过 3 次（最近一次：…）」
→ 标 semantic:true，原件进 archive（不再占注入名额）
→ 已有归纳则 S ×1.15 并累加次数
```

人类的长期记忆主体是 gist 而不是 episode——这是整套里唯一「越用越聪明」的机制。

## 8. 坏记忆：四种处理，她选

| 手段 | 行为 |
|---|---|
| `forget` | 真删；写 `tombstones`，**不能复活** |
| `seal` | 封存：不主动注入、不参与回忆；按类检索仍可能翻到；到期只归档 |
| 自然沉底 | 什么都不做，遗忘曲线自走 |
| `revise` | 订正（记错了）：留 `oldText`、`revisions+1`、`S ×1.3`；合并时新版本必胜 |

原则：**难过的事不自动删。** 删是不可逆的，而她有权保留——只是不必天天想起。

---

## 9. 已知边界（诚实清单）

1. 不懂同义词：只认 2-gram 字面重合，`地铁站` / `地铁`、`开心` / `高兴` 都需要人肉校准。
2. 权重全是手调的：`0.55/0.25/0.20`、`[1,0.55,0.3,0.16]` 没有数据支撑，是经验值。
3. 写不写靠模型自觉：`shouldEncode` 只挡明显流水，剩下全靠 agent 判断。
4. 归档 600 条之后真丢最旧细节：归档不是无限的。
5. 时间尺度粗：小时级衰减，不是秒级。
6. 没有多用户隔离：一台机器一个脑（用 `space` 才能分开）。
7. 「情绪」是猜的：靠关键词（难过 +0.7），不是真情感。
