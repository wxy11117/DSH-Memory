# 记忆活动面板

这是从 `0.2.0-preview.1` 开始提供的本地功能，当前试安装包为 `0.2.0-preview.3`。未自动替换已安装插件，也未自动发布 GitHub。

## 面板能看什么

- 每日新增、成功回忆、强化、抑制、订正、封存、删除、归档、归纳和层级变化。
- 按日期、活动类型和关键字查看时间线，点击查看操作详情。
- 所选日期及之前六天的活动数量。
- **当前**记忆库的活跃数、归档数、四层分布和模型留存率。
- 词语关系网：随返回数据持续更新，默认从球心向外分三层球面展开，可逐步展开到六层；拖动观察前后关系、滚轮缩放，点击词语切换球心并触发球面波纹。
- 导出不包含正文、空间标识和访问凭据的 Markdown 日报。

界面沿用官网的奶油纸色与暖橙配色，加入圆润卡片和蓝发大肥鱼角色。所有资源随包提供，不需要 CDN。

## 三维差序联想图怎么读

默认中心来自当前可展示记忆中较重要的一条：综合钉住状态、重要度、稳定性、是否归纳和是否归档排序，再从其关联词中选取代表词。这是展示用的排序规则，并不宣称能客观确定“最核心的人格记忆”。点击其他词后，它会成为新的联想中心；“回到核心”可恢复默认中心和视角。

- 一圈是直接连接，二圈、三圈是通过其他词间接到达的连接。默认每个词最多沿六条最强连接展开三圈。“展开更多”依次将深度提高至四、五、六圈，每词连接上限提高至 10、14、18；显示节点上限依次为 90、180、360、600。“收回三层”恢复默认范围。
- 第一层分支分布在球面不同方向，后续关联词围绕父分支的方向展开；同层较强关系更靠近球心。节点与连线向外逐层变淡。
- 图中距离来自已有词语的共现关系，不是语言模型计算出的语义相似度。没有连接或未进入本轮扩散的词不会被编造连线，数量在图下说明。
- 展示强度沿路径递减：`a_child = a_parent × g_k × min(1, 0.45 + w/4)`，其中 `g_1=0.55、g_2=0.30、g_3=0.16`，`w` 是连接权重；核心为 1。满强度路径的三圈强度依次为 `0.55、0.165、0.0264`。扩展视图的第四圈起使用 `g_k=0.16×0.55^(k-3)`，仅用于展示，不改变引擎原有的三圈联想规则。
- 展示层级取扩散范围内最少经过的连接数，同层保留强度最大的父路径。因此环形网络的可视层级不等于引擎某次检索输出的完整复现。

每个词有真实三维坐标 `P_i = r_i d_i`，其中 `d_i` 是单位方向向量，`r_i` 来自关系层级与强度。视角旋转保持三维距离，透视投影使用 `3.4 / (3.4 - z)` 的缩放系数；前方节点更大、更清晰，后方节点更小、更淡。球面网格包含前后半球，节点按深度绘制，使用离线 Canvas 完成投影，无外部绘图库。

节点采用自然星光样式：微小亮点、羽化光晕和缓慢错开的明暗变化。核心较亮，外层更细、更淡；只有变亮时出现很轻的光芒，没有硬边轮廓或立体球面高光。连线和球面网格也相应减淡。

拖动图形改变观察角度，滚轮缩放；方向键和左右旋转按钮也可操作。点击词语文字或光点时，球心重排，球面波纹向三维空间扩张，光点沿连接向外传播。暂停自动旋转仍保留轻微闪光，也可手动旋转和触发波纹；系统开启“减少动态效果”时停止持续闪烁，点击改用短暂高亮。可见时绘图约限制为 30 帧/秒，闪光只在本地绘制，与每 60 秒读取数据分别运行。

这些交互只改变本地视图，不会调用强化、回忆、遗忘或写入接口。相关记忆可通过“查看关联”打开。

## 随数据生长

已连接本机服务且页面可见时，每 60 秒读取一次最新快照；返回页面后也会刷新。新增词从父分支渐入，新连接与连接强度变化会短暂高亮。所选中心、缩放和旋转角度保留；同一父路径与层级的旧节点尽量沿用位置，关系变化需要重排时平滑过渡。若所选词退出数据，则重新选择默认中心。

首次打开、返回页面和手动刷新仍可立即读取。独立文件观察的后台扫描也默认每 60 秒一次。刷新只访问本机数据，不调用大模型，因此不消耗模型 Token；降低频率减少的是本机请求、文件扫描与计算开销。插件操作日志仍在操作发生时记录，面板按分钟读取。

关系图以每次返回的数据为准：词语或连接退出候选数据时同步移除，不会永远累积旧节点。新词没有当前中心的可达路径，或落在默认范围之外时，先计入候选词；可点击“展开更多”或从下拉框选择它。不会为了让图看起来变大而编造连线。

图下的“新出现/退出当前数据/强度变化”比较最近两次返回的候选图，不等于刚创建或删除了几条记忆；强度排序变化也可能导致词项进入或退出候选池。首次打开、切换记忆空间或重新导入文件只建立基线。页面关闭期间的图变化不会逐帧重播，活动历史仍以已记录日志为准。

合成演示提供“演示生长”按钮，依次加入海边、摄影、相册等四条合成经历，用于观察新分支；它不会写入真实记忆库。本地导入的 JSON 是一次快照，需重新导入才会更新；要自动生长，应通过插件面板或文件观察服务连接数据。

## 三种打开方式

### 1. 已安装本预览版插件

插件启用后，面板服务自动在本机后台启动，不需要先发消息触发，也不会自动弹出浏览器。想查看时对 DSH 说：

> 给我记忆面板地址。

DSH 通过 `hp_dashboard` 返回当前完整链接，点击即可查看。如果模型未调用工具，可明确说“请调用 hp_dashboard，把完整链接给我”。服务只绑定 `127.0.0.1`，使用临时访问凭据。同一次插件运行中反复取址共用一个服务和地址；重启 DSH 或重新加载插件后应重新获取地址，不应把旧端口当作固定入口。

面板在后台待命时不执行浏览器绘图或定时页面请求；打开且可见后每 60 秒读取一次，首次打开、返回页面和手动刷新仍立即读取。关闭网页不停止插件记录，退出 DSH、停用或卸载插件会关闭面板服务。文件观察模式的 60 秒扫描随服务启动，不依赖网页是否打开。

自动启动采用独立的异步流程，不新增 DSH 服务依赖，也不阻塞记忆工具与提示词挂载。启动失败会记录提示，之后获取地址时可以重试；并发请求不会重复启动。即使插件在服务尚未启动完成时卸载，迟到的服务也会关闭。

默认 `activityLog: true`，从插件加载后开始记录；设为 `false` 可关闭新增活动记录，面板仍可查看当前状态与已有历史。活动日志放在记忆家目录下的 `activity/`，默认保留 90 天。CLI 的记忆操作也会记录，直接调用纯引擎模块的其他程序需要自行接入记录器。

### 2. 先看界面，不安装

直接用浏览器打开 `dashboard/index.html`，即可体验明确标注的合成演示。点击“打开本地脑文件”选择 `brain.json`，在浏览器内查看当前状态，不上传文件。

也可运行：

```sh
node tools/dashboard.mjs --demo --open
```

### 3. 观察已有记忆文件，不替换旧插件

```sh
node tools/dashboard.mjs --home "<记忆家目录>" --space default --open
```

如脑文件在其他位置：

```sh
node tools/dashboard.mjs --file "<brain.json 的完整路径>" --space "<记忆空间>" --activity-dir "<活动记录目录>" --open
```

保持启动进程运行，关闭进程即停止观察。支持 `--port 0` 自动选择空闲端口；需要 Node.js 22 或更高版本。

## 记录口径

| 模式 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 插件操作日志 | 接入后，经插件工具、后台任务和提示词整理执行的已记录操作 | 模型是否真的采纳记忆、对话最终是否正确；未接入记录器的其他程序行为 |
| 文件观察 | 面板运行期间，约每 60 秒发现的文件状态变化 | 期间每一个中间操作、变化的确切原因、未落盘的检索，以及面板离线时的完整历史 |
| 本地文件快照 | 该文件中的当前记忆与关系网 | 过去每天做过什么 |
| 合成演示 | 界面和操作示例 | 任何真实用户的运行表现 |

第一次观察只建立基线，**不会把已有记忆记成今天新增**。日期筛选只影响活动日志，当前记忆库数字与关系网仍然是当前状态。后台查询不会调用引擎的 `stats`、`render` 或 `sweep`，因此打开面板不会清扫或修改记忆。

“成功回忆”依据引擎回忆字段的实际更新记录，检索和上下文准备单独计数。一次操作可能涉及多条记忆，也可能产生强化、层级变化等多个事件；面板的“活动次数”不是模型调用次数。

“永久”是高稳定性档位，留存率仍按指数模型计算。留存率不等于事实可信度。词语连线表示共现，不等于因果或真实神经连接。

## 内容与边界

正文默认隐藏，可手动显示。日志只保存记忆编号、时间、类型、分类和必要数值，不保存正文或检索话题。查看旧活动时，正文来自当前脑文件，**不是事件发生时的正文副本**；已删除或封存的正文不再展示。封存条目的专有词不单独暴露在图中。

活动日志记录的是进程内操作，不是跨文件的事务型数据库审计。异常断电可能使最后一段日志与尚未落盘的记忆存在差异；日志写入失败不会阻断记忆工具。原有记忆引擎的规则与已知缺陷未在本功能中全面重写。

关系网先选取最多 600 个可见词语节点和 1800 条边，优先较强连接；再按当前展开范围显示可达节点。这是有上限的可视化候选池，不是无限渲染，也不限制脑文件本身的存储量。上方总数是整个存储关系网的数量，“另有若干词未展开”只计候选图内未展开的词。单日时间线最多显示最近 1500 条，统计仍覆盖当天可读取记录。

本地桥接扩展会使用文件观察模式，不改动桥接服务或接口。安装新插件应先在独立 profile 验证，保留原插件目录与记忆备份。
