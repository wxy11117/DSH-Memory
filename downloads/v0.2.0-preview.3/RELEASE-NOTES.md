# DSH-Memory v0.2.0-preview.3 · 记忆活动面板公开测试版

本版本为记忆插件增加本机活动面板：查看每日新增、检索、回忆、归档、四层分布与三维词语关系网。插件启用后服务在后台启动，调用 `hp_dashboard` 获取地址，点击后打开页面。

这是 **Pre-release（公开测试版）**，已在下述 Windows / DSH 环境验证，欢迎先备份后试用。

## 普通用户如何使用

1. 备份记忆并保留旧插件目录，正常退出 DSH，将 ZIP 完整解压到长期保留的新目录。
2. Windows 双击 `tools/install.cmd`。需要 Node.js 22+；安装器会寻找并验证可用运行时，包括 DSH 自带的运行时，不要求 Git 或 npm。
3. 安装登记通过后重新启动 DSH，确认 16 个 `hp_*` 工具可用。
4. 对 AI 说“请调用 hp_dashboard，把完整链接给我”，点击返回的本机链接。

默认本地模式下，页面可见时每 60 秒读取该用户的最新记忆；首次打开、切回页面和手动刷新会立即请求。只有插件已收录的记忆会被展示。页面默认隐藏正文，可自行切换显示。面板只读，读取和动画不调用大模型；对话中的记忆注入仍占用上下文。

安装采用目录链接，必须保留解压目录。重启或重载插件后重新获取面板链接。

## 修复内容

- 修复部分 Electron 运行时下，递归清理目录链接可能误删旧插件源码的问题。
- 升级时仅移除链接自身，真实旧目录保留为备份；切换失败时尝试恢复原链接和登记。
- 加载测试使用独立副本，清理不遍历链接指向的源码。
- 回退旧版本时，使用本版安装器的 `-Plugin` 参数指定旧目录，避免再次运行旧版清理代码。
- 延续 systemPrompt 依赖声明修复，验证真实 Cordis 启动、服务替换、面板卸载和重载。

## 使用边界

- 当前验证范围为上述 Windows / DSH 环境，不代表所有操作系统、DSH 版本和第三方插件组合都已验证。
- 新记忆由 AI 调用工具提交；插件不自动保存每句聊天。提醒不是独立推送服务。
- 保持 `followSession=false`；同一个插件的默认空间用于跨会话共享，不是不同账号之间的安全隔离。
- 正常卸载或退出会补刷待写数据；强杀进程、断电仍可能丢失尚未保存的变化。
- 记忆本地保存，注入对话的内容可能随 DSH 请求发送到用户选择的模型服务商。
- 图谱表示词语共现关联，留存率是模型计算值，不代表事实正确率或人类记忆验证。

安装与回退详情见包内 `docs/TRY-PREVIEW.md`。旧的 preview.2 及更早安装器不再建议使用。
