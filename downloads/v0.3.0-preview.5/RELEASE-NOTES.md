# DSH-Memory 0.3.0-preview.5 · 预览测试版

本版为预览测试版，请先在独立测试环境验证。下载本 Release 附件中的插件 ZIP 和 SHA256SUMS.txt。GitHub 自动生成的源码 ZIP 不是同名安装包附件。

## 这一版可以做什么

- **每只鱼一个空间**：首次由用户确认会话绑定。不同空间分别读写、检索、自动注入，并查看自己的看板和小屋；未绑定时拒绝记忆读写。同一只鱼换会话，选回已有空间。
- **本地三维海边小屋**：AI 通过工具查看房间、安排活动、控制环境与便签；状态保存在插件的数据目录。三位动作编号表示楼层、活动和事项，执行结果通过回执返回；排队不等于完成。
- **小屋与看板互通**：小屋电脑打开当前空间看板，看板也可进入小屋。看板可见时约每 60 秒读取本地数据。完整地址由 hp_room / hp_dashboard 返回，重启或改绑后重新获取。
- **可选自主生活**：默认关闭。页面确认模型费用后才开启，默认每 30 分钟唤醒、每天最多 12 次；需要小屋页面可见且指定会话在线空闲。界面可独立关闭，已保存的记忆与存档保留。
- **带上旧记忆**：离线复制旧 brain.json 到尚不存在的新目录，保留原件及完整备份；可以一一映射不同源空间，保留归档、稳定性、订正、语义归纳和词语关系网。迁移后仍需用户确认会话绑定。

保留四层稳定性分档、指数遗忘、回忆强化、语义归纳、差序联想和活动看板。preview.4 到 preview.5 未改变记忆算法或参数。

## 相比 preview.4 的修复

- 官方带注释的空模板 `[]` 可以被安装器正确解析。
- 新迁移工具不覆盖原库、不自动合并，先预演再复制，报告提供数量与完整性校验。
- 安装拒绝提示提供下一步；复杂 YAML、旧桥接、重复实例及冲突数据目录仍会被拦截。
- 修正两条旧冒烟脚本的测试记忆目录，严格验证 22 个工具及提示词缺失时的取回路径。
- 明确 profile 不等于完整宿主隔离：相同 DSH_HOME 下会话与工作区、定时任务仍共享。
- 看板工具提供结构化的 space、url 和 refreshIntervalMs，自动化无需猜端口。

## 安装及迁移

先备份旧配置和记忆，完整解压 ZIP，运行 `tools/local-check.cmd`。想先看看小屋，可以运行 `tools/preview-room.cmd`，演示不连接 AI。

实际接入需指定独立测试 profile，先 `--dry` 预演；首次用 `hp_space` 由用户确认绑定，再调用 `hp_room` 或 `hp_dashboard`。保留安装目录。不要同时挂载同名新旧插件。

详见 [安装说明](https://github.com/wxy11117/DSH-Memory/blob/v0.3.0-preview.5/docs/LOCAL-TRIAL.md)、[旧记忆迁移](https://github.com/wxy11117/DSH-Memory/blob/v0.3.0-preview.5/docs/MIGRATE-SPACES.md)、[本地地址说明](https://github.com/wxy11117/DSH-Memory/blob/v0.3.0-preview.5/docs/LOCAL-ENDPOINTS.md)。

旧库里已经混在一起的不同鱼不能自动拆分；多个独立源文件的增量合并暂不处理。QQ 侧车格式仅支持离线复制，不持续同步。旧 brain.json 不能还原每天的活动日志或房间历史。

## 费用与数据

看板刷新、浏览器动画、本地消息与文件保存不调用模型，也不新增付费云同步。聊天、工具选择、记忆注入和开启后的自主思考使用原有模型额度；唤醒次数上限不是费用上限。关闭自主生活后停止后续唤醒，已发出的调用仍可能完成并计费。

记忆和存档默认保存在用户电脑；注入对话的内容可能随宿主请求发送给用户选择的模型服务商。完整本机链接含访问凭据，只给自己使用。空间隔离不替代操作系统账户权限。

正常退出 DSH 使待写数据落盘，强杀进程或断电可能丢失未保存变化。测试前保留旧包、旧配置与记忆备份；卸载插件登记不会删除存档，迁移副本中的新变化不会自动回流旧库。
